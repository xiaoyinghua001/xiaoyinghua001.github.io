Local Tool

授权视频备份器

本地运行的学习资料备份工具。GitHub Pages 负责说明和入口，下载与合并由本机服务完成。

打开本地服务 查看服务代码

启动方式

在本机终端进入这个目录后启动服务：

cd douyin-download-tool
python3 app.py

保存位置

下载和合并后的文件会保存到系统下载文件夹：

~/Downloads

使用边界

  • 只保存你自己发布、已获授权、或允许离线备份的内容。
  • 不破解平台限制，不保证去水印。
  • 抖音媒体链接有时效，403 或置灰时先重新播放视频刷新链接。
