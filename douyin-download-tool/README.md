# 授权视频备份器

本地运行的小工具，用于保存你自己发布、已获授权、或允许离线备份的视频内容。

这个工具分两层：

- GitHub Pages 里的页面只作为入口和说明。
- 真正下载/合并由本机 Python 服务运行在 `http://127.0.0.1:8765`。

## 启动

```bash
cd douyin-download-tool
python3 app.py
```

启动后打开：

```text
http://127.0.0.1:8765
```

## 依赖

需要本机可用：

```bash
yt-dlp
ffmpeg
```

可以用 Homebrew 安装：

```bash
brew install yt-dlp ffmpeg
```

## 文件位置

下载和合并后的文件默认保存到系统下载文件夹：

```text
~/Downloads
```

## Chrome 插件配合

如果需要在抖音播放页里使用 `Merge A+V`，请加载本地修改过的 Chrome 插件版本。不要把第三方插件整包发布到公开仓库；这里只保存本地服务代码和说明。

## 边界

- 只建议下载你有权保存的内容。
- 不破解平台限制，不保证去水印。
- 抖音媒体链接常有时效；如果 403 或置灰，重新播放视频并刷新链接后再试。
- 如果平台临时风控，请暂停一段时间，不要连续反复请求。
